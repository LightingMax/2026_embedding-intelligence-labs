# 实验架构与章节边界

## 统一能力链

```text
原始传感器与状态
  → SceneState（第1章）
  → TaskSpec（第2章）
  → PlanSpec（第3章）
  → MotionCheck / 轨迹与控制反馈（第4章）
  → 学得模型与能力证据（第5章）
  → RuntimeState / 事件与完成证据（第6章）
```

第2章的认知负责确定指令、对象、目标、约束和未知项的语义。第3章的任务规划在技能目录、资源、代价和风险下选择动作及顺序。物理约束并非二者的唯一分界：认知可以识别“杯口向上”这项约束，任务规划把它传入技能并据此选方案，第4章的运动规划再判断连续空间中是否存在满足约束的路径与轨迹。

## 三种规划

| 规划层次 | 本书位置 | 典型问题 | 输出 |
| --- | --- | --- | --- |
| 语言或模型内的候选规划 | 第2、3章交界 | 指令可能需要哪些步骤 | 候选任务结构 |
| 任务规划 | 第3章 | 调用哪些技能、顺序和失败分支 | `PlanSpec` |
| 运动与轨迹规划 | 第4章 | 身体怎样无碰撞、可达且稳定地运动 | 路径、轨迹、控制参考 |

第6章的智能体编排负责在运行时启动、监控、取消和恢复这些计划，不重新定义任务规划或运动规划算法。

## 后端边界

- Mock后端验证接口、状态转换和故障语义。
- ROS 2后端验证消息、动作、时间和取消语义。
- Isaac Sim后端验证传感器、几何、接触和仿真时钟。
- Unitree DDS适配验证与G1接口的一致性。
- 实机部署需要独立的硬件安全与验收流程。
